# Source Layout

- `app/` — application entry point and version.
- `core/chrome_capture.py` — Chromium CDP capture.
- `core/analyzer.py` — history-driven passive analysis, controlled testing, evidence rules.
- `core/payloads.py` — curated CTF/write-up payload knowledge base, family applicability and source metadata.
- `ui/main_window.py` — Dashboard, HTTP History, Repeater and Analyzer UI.
- `requirements.txt` — runtime dependencies.
- `run.sh` — launcher.
