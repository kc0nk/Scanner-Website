# KCONK Navbar v10

Primary navigation is rebuilt as a fixed rail with exactly eight modules:

1. DASHBOARD
2. WORKFLOW
3. PROXY
4. INTRUDER
5. REPEATER
6. SCANNING
7. COLLABORATOR
8. META WORKFLOW NC

The module rail uses fixed button widths and does not rely on stretch/compression. The rest of the application remains an intentionally blank content canvas until the navbar is finalized.
